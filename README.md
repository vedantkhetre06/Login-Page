# 🧠 Quiz App with Login & Signup

A simple React-based Quiz Application that includes user authentication (Login & Signup) and quiz navigation using React Router.

---

## 🚀 Features

* 🔐 User Signup & Login (LocalStorage based)
* 🧭 Protected Account Page
* 📝 Start Quiz functionality
* ⚛️ Built with React Hooks
* 🔄 Client-side routing using React Router
* 🎨 Clean and responsive UI

---

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6)
* React Router DOM
* CSS3
* LocalStorage

---

## 📂 Project Structure

```
src/
 ├── component/
 │    └── Quiz.js
 ├── App.js
 ├── App.css
 └── index.js
```


## ⚙️ How It Works

* User creates an account using Sign Up
* User logs in with registered credentials
* After login, user reaches the Account page
* User clicks Start Quiz
* Quiz runs and calculates the score
* Final score is displayed to the user
